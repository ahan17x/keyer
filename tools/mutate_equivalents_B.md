# Equivalent mutants, group B (core, pin unit, capture and replay, program memory)

Survivors of the full campaign (GitHub run 37260274984) in `keyer_core.v`,
`keyer_pins.v`, `keyer_capture.v` and `keyer_imem.v` that no test or proof
can kill because no behaviour at the chip's pins or in any state the tests
may read differs, and that Yosys cannot prove equivalent by itself (they
differ only in states that cannot occur, or only in a value nothing reads).
Same format as `tools/mutate_equivalents.md`; a row whose line of source
changes gets a new id and must be judged again.

The miter checks named below compare the original module with the mutated
one, same inputs, both reset in the first cycle and `rst_n` free afterwards,
by k-induction (yowasp-sby, z3); the internal registers are brought out on
an added port so the induction can state their equality. Each was also run
on non-equivalent mutants of the same module as a control, and those fail.
